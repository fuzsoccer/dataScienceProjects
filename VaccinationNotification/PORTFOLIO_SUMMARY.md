# Short project description

Analyzed an existing five-arm vaccination messaging experiment involving 42,481 patients in Python. Built a self-contained notebook covering data audits, baseline balance, multi-arm comparisons, robust confidence intervals, randomized reasons-count interactions, and sensitivity analyses. Reproduced source models and independently validated conventional estimates against R. Pooled high-risk messaging exceeded passive control by 2.57 percentage points; its advantage over a basic reminder and the benefit of additional reasons remained uncertain.
