# Source data and third-party materials

This is a secondary analysis. Original trial, patient data, message designs, manuscript, dictionary, and R code belong to their respective authors and rights holders; this project does not claim authorship of them.

The OSF project's public API returned `node_license: null` on October 27, 2026. The linked earlier preprint has a CC BY 4.0 license, but that separate record is not treated as a license for the data project. Public availability alone is not recorded here as a redistribution grant.

For that reason, the publication package excludes raw patient-level files, third-party R code/dictionaries, and supporting PDFs. It contains this analysis's notebook, Python implementations, narrative, aggregate results, and source links. To reproduce it, obtain the source ZIP from [OSF](https://osf.io/mqbux/) under its applicable terms, then run `src/prepare_data.py`. The complete local working package retains the user-supplied materials for their own analysis and is not the publication package.

No blanket license is applied to third-party material. The Python models translate the statistical formulas documented by Rosenbaum and colleagues; the original research must be cited when presenting this work.
