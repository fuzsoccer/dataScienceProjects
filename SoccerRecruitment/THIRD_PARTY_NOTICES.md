# Data and third-party attribution

**StatsBomb Open Data** supplies events, lineups and match metadata. Source: https://github.com/statsbomb/open-data. Read its README and supplied LICENSE.pdf for applicable terms. Public findings acknowledge StatsBomb and include its requested logo. Raw data is acquired by users and not bundled here.

`docs/assets/statsbomb-logo.png` is the unmodified provider logo from the source repository at revision `4b73468fc5b0f1950f9f66fada70ad3a4f9327cb`, path `img/SB - Icon Lockup - Colour positive.png`. It remains a provider asset and is included for source acknowledgement. The repository's analytical code does not grant rights to that asset or relicense the underlying data.

**Metrica Sports** supplies the separate anonymized tracking/event sample. Source: https://github.com/metrica-sports/sample-data. Its README requests responsible use and public acknowledgement. The tracking sample is not linked to StatsBomb players and is not bundled.

**Expected Threat methodology:** Karun Singh, “Introducing Expected Threat (xT),” https://karun.in/blog/expected-threat.html; socceraction documentation, https://socceraction.readthedocs.io/en/latest/documentation/valuing_actions/xT.html. This project implements its own explicitly documented variant; it does not copy library code or redistribute a pretrained external xT surface.

JupyterLab, ipykernel and matplotlib are installed as development/notebook tools and retain their own licenses. No open-source license for this project's original code has been selected in this snapshot; provider data/branding rights remain separate from any future code-license choice.
